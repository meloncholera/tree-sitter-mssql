# Security

Found a parser crash or hang on some input? Please include the input (or a minimized version) and which binding you used (Rust, Node, or the C API) in a normal GitHub issue. If it looks like it could be used to cause trouble for a downstream consumer before a fix ships, use [GitHub's private vulnerability reporting](https://github.com/meloncholera/tree-sitter-mssql/security/advisories/new) instead.
